    • __construct() — Пустой конструктор
    • Add() — Добавить карту с массивом точек на ней $array[] Это масив масивов точек $array[]['address'] Адрес $array[]['persons'] Контактные лица $array[]['description'] Любое описание Если в массиве $array только 1 объект, то он добавляется со всеми данными в каждую колонку + JSON точки в locations. Если же точек больше одной, тогда весь $array конвертируется в JSON и всё это кладётся в колонку locations. Это сделано для того, чтобы избежать повторений в добавлении новых точек через API и искать добавленные точки по адресу, названию и описанию.
    • AddTextToMap() — Добавляет любой текст к карте
    • GeneratePoint() — Создаёт значения lat и long для указанной точки. Если в базе есть уже такая карта с теми же address, persons и description - вернёт её ID
    • Get() — Получение массива карты по её ID
    • GetAll() — Получение всех ТОЧЕК из базы данных в одном массиве
